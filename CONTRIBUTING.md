# Contributing to c2plan9

Thank you for considering a contribution to **c2plan9**! `c2plan9` is the low-level machine code compiler and Plan 9 assembly transpiler powering the vectorization pipeline in `foundation`, `mach`, and `seal`.

We welcome bug fixes, disassembler instructions support, register allocator refinements, and architecture extensions.

## Ground Rules

- **Deterministic Code Generation:** Given identical C source code and Clang versions, the emitted Plan 9 assembly must remain bit-for-bit deterministic.
- **Go ABI Conformance:** Generated assembly must strictly follow Go internal ABI conventions (stack frame sizing, register clobber lists, argument offsets, return values).
- **Zero Runtime Dependencies for Consumers:** Code generated by `c2plan9` must execute directly with the Go toolchain without requiring external C libraries at runtime.
- **Backward Compatibility:** CLI flags and stub generation APIs are permanent contracts.

## Getting Started

```bash
git clone https://github.com/lemon4ksan/c2plan9
cd c2plan9
go test ./...        # run unit tests
go test -race ./...  # test with race detector
make lint           # run golangci-lint
```

## Workflow

1. **Fork** the repository and create a feature branch from `main`.
2. Implement your changes adhering to assembler encoding rules and Go ABI conventions.
3. Add unit and regression tests in `c2plan9_test.go` or `arm64_c2plan9_test.go`.
4. Verify that `golangci-lint run ./...` reports 0 warnings and tests pass with `-race`.
5. Submit a Pull Request targeting `main` using the provided PR template.

## Commit Style

Use [Conventional Commits](https://www.conventionalcommits.org/):

```text
feat(disasm): support AVX-512 VPERM2B instruction translation
fix(emitter): correct stack frame alignment offset when frame size > 256 bytes
perf(parser): eliminate slice allocation during ELF symbol resolution
docs: document ARM64 Crypto extension transpilation workflow
```

## Tests & Benchmarks

| Command | Purpose |
|---|---|

| `make lint` | Run `golangci-lint` verification |
